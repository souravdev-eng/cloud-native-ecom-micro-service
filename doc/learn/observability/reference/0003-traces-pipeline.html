The path

  → startTelemetry()               common/src/observability/telemetry.ts
      auto-instrumentation: http express mongodb mongoose pg ioredis redis amqplib

  → alloy-srv:4318                 OTEL_EXPORTER_OTLP_ENDPOINT (k8s/config/app-config.yml)

Where export goes

testSpanExporter given
Simple processor → redactor → the test's exporter
NODE_ENV=test or no endpoint
Noop processor: nothing is sent, but IDs still exist (logs keep trace_id)
otherwise
Batch processor → redactor → OTLP/HTTP to the endpoint

traceparent

00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
ver  trace-id (32 hex, kept)         parent-id (16)   flags 01 sampled / 00 not

Continue it, never replace it. On AMQP (ticket 06+) it goes in message headers, never the payload.

Find a trace

curl -sk -i … | grep -i x-trace-id                  # from any auth response

{ resource.service.name = "auth-service" }
{ resource.service.name = "auth-service" && duration > 50ms }
{ resource.service.name = "auth-service" && span.http.response.status_code >= 400 }
{ status = error }

resource. = the process/service · span. = one span's attributes.

Reading a waterfall

SERVER
An incoming request (usually the root)
CLIENT
An outgoing call: HTTP or a database
INTERNAL
In-process work, such as Express middleware
gap under a parent
The parent's own code (for a login: bcrypt)

The links (grafana.yml)

# Loki → Tempo: derived field
matcherRegex: '"trace_id":"([0-9a-f]{32})"'   datasourceUid: tempo

# Tempo → Loki: tracesToLogsV2
tags: service.name → service    shift ±5m
query: '{$${__tags}} | trace_id="$${__trace.traceId}"'

Invariant: the logger's service must equal startTelemetry({ serviceName }). The options beat OTEL_SERVICE_NAME. In provisioning files, $$ escapes Grafana's env expansion.

Failure modes

Alloy down
Requests fine; spans dropped from auth's bounded queue
Tempo down
Requests fine; Alloy's queue fills, then drops
tracing imported late
No error; Express and DB spans silently missing
"trace not found"
>72 h old · sampled out (flags 00) · outage · not flushed yet
