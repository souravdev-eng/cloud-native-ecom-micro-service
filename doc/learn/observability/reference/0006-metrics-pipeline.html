Metrics pipeline

Auth observes → Alloy scrapes → Alloy remote-writes → Prometheus stores → Grafana queries. An exemplar points from a metric observation to a Tempo trace.

Names that must match

Service
auth-service in the bundle, logger, tracing bootstrap and dashboard dropdown. The issue’s “auth” is the service shorthand.
Environment
local in the cluster config; metrics.ts uses the shared environment default. A process outside the cluster may use a different value.
Duration
OTel instrument: http.server.request.duration, seconds. Exported prefix here: http_server_request_duration.
Metric labels
service, environment, method, route, status_class. Route is a template; unmatched paths use unmatched.
Datasource UIDs
prometheus, loki, tempo.

Find the owner

auth/src/app.ts
Mounts the bundle before route middleware.
common: http.ts
Trace response header, response-finish timing, route/status selection, masked access log, /metrics mount. Scrapes are logged but excluded from HTTP metrics.
common: metrics.ts
Histogram, metric provider, runtime observers, OpenMetrics handler, meter/tracer accessors.
common: exemplars.ts
Latest sampled trace example per combination, attached to +Inf; capped at 1,000 combinations.
auth-depl.yml
Pod annotations opt into /metrics scraping on port 3000.
alloy.yml
Pod discovery, annotation filtering, 15-second scrape, OpenMetrics protocol, remote-write endpoint and exemplar forwarding.
prometheus.yml
15-day retention, remote-write receiver, exemplar storage and recording rule.
grafana.yml
Prometheus exemplar → Tempo destination, plus Tempo traces-to-metrics mapping from service.name to service.
grafana-service-detail.yml
Dashboard JSON, environment/service variables, queries, panels. Includes a dependency-span panel beyond the ticket’s minimum.

Read a panel precisely

Request rate
Per-route growth of _count, requests/sec.
Error rate
Same calculation restricted to 4xx or 5xx; requests/sec. To obtain a fraction, divide errors by total requests over matching groups/windows.
Latency
Bucket rates combined by le and route, then histogram_quantile for p50/p95/p99. Percentile estimation and aggregation.
Error logs
Loki service and level=error selection, then JSON environment filtering. HTTP access logs are info level even for a failed response.
Slow recent traces
Tempo searches traces over 1 second, sorts returned results by duration, and displays ten. The search limit is 1,000; it does not establish a global top ten.
Runtime
Event-loop lag is the monitor’s mean delay in seconds (not reset each scrape); heap is current used bytes; GC panel estimates p95 of recorded GC durations. Their correlation with latency is a clue, not a causal proof.

Small business-instrument example

const logins = getServiceMeter('auth-service')
  .createCounter('auth.logins');
logins.add(1, { result: 'success' });

const tracer = getServiceTracer('auth-service');
tracer.startActiveSpan('check-policy', (span) => {
  try { /* your synchronous work */ }
  finally { span.end(); }
});

The meter shares the /metrics provider; the tracer uses the tracing bootstrap’s provider. HTTP/runtime metrics get service/environment attributes explicitly in metrics.ts; custom business instruments must choose their own bounded attributes. End an asynchronous span only after its awaited work completes. Usage note: common README.

Review and verification

  • Route templates, status classes and bounded dimensions; never user IDs, raw URLs or trace IDs as metric labels. Prometheus label guidance.
  • Exactly one structured access log per finished request; sensitive query values masked before logging.
  • /metrics returns OpenMetrics text; scraping preserves exemplars. Scrape reference.
  • Sampled trace reaches Tempo, forwarding preserves its exemplar, and Grafana’s destination UID/name match. Exemplars reference.
  • Dashboard JSON and UIDs parse; promtool accepts rule syntax. These checks do not establish live panel rendering or successful exemplar clicks.
