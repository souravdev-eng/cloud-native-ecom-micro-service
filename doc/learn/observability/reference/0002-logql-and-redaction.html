LogQL and redaction sheet

Query shape

{labels}  |= "text"  | json  | field="x"
selector  line filter parser label filter      ← cheapest to most expensive

Recipes

# all auth warnings
{service="auth-service", level="warn"}

# text, then parse, then field
{service="auth-service"} |= "Login failed" | json | reason="wrong_password"

# numeric / regex field filters
| json | status >= 400
| json | route=~"/api/users/.*"

# structured metadata (no parse needed)
{service="auth-service"} | trace_id="<32 hex>"

# exclude noise
{service="auth-service"} != "HTTP request"

# nested JSON: error.name → error_name
{service="auth-service"} | json | error_name="MongoServerError"

# count by field over a window (metric query)
sum by (reason) (count_over_time({service="auth-service"} |= "Login failed" | json [1h]))

# every auth stream, including the unstructured {service="auth"}
{service=~"auth.*"}

Operators

line filters
|= contains · != doesn't contain · |~ regex · !~ not regex
label/field filters
= != =~ !~, and for numbers or durations > >= < <=. Combine with and/or.

Redaction: where

createLogger pipeline:  normaliseErrors → redactSecrets → applySchema → JSON → stdout
spans:                  RedactingSpanExporter (same rules) → OTLP

Nothing downstream (Alloy, Loki, Grafana, Tempo) redacts anything. Only output through the logger is protected.

Rule A · Secret key names → [REDACTED]

The name is lowercased, with non-alphanumerics stripped (x-api-key → xapikey). sensitiveKeys.ts:

contains
password passwd passcode secret credential authorization bearer cookie session signature jwt apikey privatekey
ends with
token tokens pwd sid
exactly
card cardnumber cvc cvc2 cvv cvv2 pan otp

Rule B · Secret-looking text, in any string

email
jane@example.com → j***@example.com (the domain is kept)
Stripe keys
sk_/rk_ live|test, whsec_ → [REDACTED]
query params
?token=… (a secret name) → token=[REDACTED]; %40 emails are decoded, then masked

Placeholders

[REDACTED]
A secret field or key
[Circular]
An object that contains itself
[Truncated]
Deeper than 10 levels, or more than 2,000 objects
[Unreadable]
A getter or toJSON threw

Protect a new field

Add the word to one list in sensitiveKeys.ts and a case to common/src/observability/__test__/redaction.test.ts, then publish common and bump its consumers.
