Glossary

Every lesson uses these words with exactly these meanings. "Label" on its own always means a Loki label.

Signals

telemetry
Data a system gives off about itself: logs, traces, metrics.
observability
Being able to explain misbehaviour from telemetry, without adding code first.
structured log
One JSON object per line, with a fixed set of keys.
span
One timed unit of work: name, start/end, attributes, status, kind, parent.
trace
All spans sharing one trace ID; a tree from the root span.
root span
The span with no parent; where the trace started.
span kind
SERVER (incoming), CLIENT (outgoing, including DB), INTERNAL (in-process), PRODUCER/CONSUMER (messages).
span status
Unset (default, fine) · Error · Ok.
attribute
A key-value pair on a span (span.) or on the whole process (resource.).
resource
Attributes describing the process: service.name, service.version, deployment.environment, k8s pod/namespace.

Context

context
What travels with a request so that signals can be correlated: essentially the trace ID and current span ID.
active span
The span the current async call chain belongs to (AsyncLocalStorage).
propagation
Moving context between processes, for example in a header.
traceparent
The W3C header version-traceId-parentId-flags.
x-trace-id
Our response header carrying the trace ID, for lookup in Tempo.
head sampling
Keep or drop decided at the start of a trace (our ParentBased ratio sampler).
tail sampling
Decided after seeing the whole trace (Alloy, a later ticket).

Pipeline

OpenTelemetry (OTel)
The vendor-neutral API/SDK we instrument with.
OTLP
OTel's wire protocol (gRPC 4317, HTTP 4318).
auto-instrumentation
Plugins that patch libraries at load time to create spans.
telemetry bootstrap
startTelemetry: one call that configures the SDK.
collector
The process that receives or tails telemetry and forwards it: Alloy.
Alloy
Grafana's collector; a DaemonSet here, one per node.
Loki
Log store; indexes labels only.
Tempo
Trace store; queried with TraceQL.
LGTM
Loki, Grafana, Tempo, Mimir/Prometheus: the Grafana stack.

Loki

label
An indexed key on a stream. Ours are only level and service.
k8s label
A Kubernetes object label (app: alloy). A different thing.
stream
All lines with the same label values.
cardinality
How many distinct values a label has. Keep it low.
structured metadata
Per-line key-values that aren't indexed and don't create streams (trace_id, pod, namespace).
derived field
A Grafana setting that turns a regex match in a line into a link (log → trace).

Safety

redaction
Masking secrets before telemetry leaves the process.
deny list
The secret key-name rules in sensitiveKeys.ts.
best-effort export
Telemetry may be dropped; requests must never wait for it.

Testing

seam
A place where a test can swap behaviour without editing the code under test.
fake
A working shortcut implementation (FakeChannel).
spy
A double that records how it was called (captureStdout).
characterisation test
Pins today's behaviour before a refactor.
positive control
A test proving the thing can happen, so that "it didn't happen" tests mean something.
